##Functional Requirements
ID	Functional Requirement	Source / Rationale	MoSCoW	Verification
FR1	The system shall maintain identifiable approved recipe versions for products	Each production batch must be associated with the applicable approved recipe version	Must have	Verify that a production batch can be associated with an identifiable approved recipe version
FR2	The system shall provide current ingredient availability information for production planning	Ingredient stock may be available, reserved, opened or unsuitable for a planned production batch	Must have	Verify that current ingredient availability information can be viewed for production planning
FR3	The system shall maintain a production batch record including the recipe version used, ingredient batches, actual quantities, production time, actual yield and production observations	Production staff need to record the actual production information for each batch	Must have	Verify that the recipe version, ingredient batches, actual quantities, production time, actual yield and production observations can be recorder for a production batch
FR4	The system shall record quality – check results and the release status of each production batch	Quality – check results and production output status need to be recorded before release	Must have	Verify that quality – check results and release status can be recorded for each production batch
FR5	The system shall maintain the relationship between customer orders and the production batches used to fulfil them	One customer order may be supplied from multiple production batches, while one production batch may supply multiple customer orders	Must have	Verify that a customer order can be associated with multiple production batches and that a production batch can be associated with multiple customer orders
FR6	The system shall provide information required to plan production batches	Production planning must consider orders, ingredient availability, kitchen capacity, equipment availability, staff skills, preparation time, cooling and packing requirements 	Must have	Verify that the information required for production planning can be accessed when planning a production batch
FR7	The system shall record ingredient substitutions associated with a production batch	Ingredient substitutions require review because they may affect allergen information, production quality and labelling	Should have	Verify that an ingredient substitution can be recorded and associated with the relevant production batch
FR8	The system shall provide traceability from ingredient batches through production batches to affected customer orders	Staff need to identify the ingredient batches, production batches and customer orders affected when an error is found	Must have	Verify that an ingredient batch can be traced through the relevant production batch to the affected customer orders

##Non – Functional Requirements
ID	Category	Non – Functional Requirement	Rationale	Verification
NFR1	Data Integrity	The system shall prevent a production batch record from being completed without an identifiable recipe version	Reliable identification of the recipe version used for each production batch is required for production records and traceability	Verify that the system does not allow a production batch record to be completed when no recipe version is identified
NFR2	Performance	The system shall respond within 2 seconds when saving or displaying information	A responsive system is required to support efficient day – to – day production activities	Verify that saving or displaying information completes within 2 seconds under normal operating conditions
NFR3	Security / Access Control	The system shall display only information that the user is authorised to access	Different roles may require different levels of access to production, supplier and customer information	Verify that a user cannot view information that is not authorised for their role
NFR4	Availability	The system shall be available throughout all scheduled work shifts and during order preparation activities	Staff require access to production, ingredients, quality and order information during operational activities	Verify that the system is accessible throughout scheduled work shifts and during order preparation activities
